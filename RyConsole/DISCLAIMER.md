# RyConsole 免责声明与使用条款

> 版本：v1.0（2026-09-13）
> 适用范围：RyConsole（bundle id `com.research.ryconsole`），及其全部探针脚本、AI 生成代码与构建产物。

---

## 0. 一句话

RyConsole 是一个**跑在你自己设备上**的安全研究控制台。它只对**你本人拥有、或已获明确授权**的设备使用，用于学习与研究，**不用于任何未经授权的访问**。

## 1. 定位

- 这是**研究工具**，不是成品越狱工具，不承诺任何功能可用性或稳定性。
- 用途：在自有设备上验证沙盒 / 访客 / 内核接口的**可达性与权限边界**，记录证据，辅助研究。
- 使用者需具备相应的技术判断力。不具备时请勿使用。

## 2. 允许的用途

1. 在**你本人拥有**的 iPhone / iPad 上进行安全研究与学习；
2. 在**已获得设备所有者明确授权**的设备上测试（如公司或学校的测试机）；
3. 参加 CTF、漏洞赏金计划（在项目规则允许的范围内）；
4. 复现公开漏洞、验证自己或他人的防御措施。

## 3. 明确禁止（红线）

1. **禁止**对他人设备、未经授权的设备、或你不拥有所有权的设备使用；
2. **禁止**用于绕过他人设备的激活锁、锁屏密码或账户认证；
3. **禁止**用于窃取、监听、跟踪或破坏他人数据；
4. **禁止**将本工具或其中发现用于**武器化 0day**、勒索软件、僵尸网络等恶意用途；
5. **禁止**在未获许可的网络上扫描、探测或攻击任何主机。

> 若你在使用中发现 Apple 产品的安全漏洞，请遵循**负责任披露**：优先报告给厂商
> （Apple Security Bounty / product-security@apple.com），而不是公开利用。
>
> 违反上述任一条，责任由使用者自行承担，与项目作者无关。

## 4. 风险告知（请务必读完）

- **可能 panic / 重启**：对内核或驱动发起非预期调用可能触发内核崩溃。
- **可能丢数据**：崩溃、强制重启或后续修复操作，可能导致未备份的数据永久丢失。
- **可能改变设备状态**：部分接口并非只读；错误调用可能改变设备状态（计数器、缓存、安全锁定等）。
- **可能触发系统安全响应**：异常调用模式会被系统记录，极端情况下影响设备可用性。
- **AI 生成代码不可预测**：AI 生成的探针可能包含错误、幻觉接口或危险调用序列。
  **运行前请自行审阅**；不要在无备份、且含不可替代数据的设备上运行自动循环。

> 强烈建议：只使用**专用测试设备**；运行前做好完整备份；
> **不要把自动循环跑在主力机或含重要数据的设备上。**

## 5. AI 参与声明

- 本项目由 AI 参与生成的内容（探针代码、脚本、文档、注释）**如实标注，不隐瞒**。
- 应用内的 AI 闭环会在运行过程中**实时生成代码**，这部分内容**未经人工逐行审核**。
- 若你把 RyConsole 或其产出对外发布（文章、视频、分享、仓库），请保留「**含 AI 生成内容**」的标注。

## 6. 数据与隐私

- 本地日志可能包含：设备型号、系统版本、内核符号名、返回码、崩溃记录。**这些内容由你自行保管。**
- 启用**联网 AI** 时，以下内容会发送到你配置的第三方服务：
  探针代码、执行结果（返回码与错误信息）、你输入的提示词。
- **不会**主动上传照片、通讯录、消息内容、账户凭据等个人数据；
  但请自行确认探针代码不会读取并发送这些内容（**尤其是 AI 生成的代码**）。
- 建议：优先使用**离线 / 本地**后端；确需联网时，使用专用 API Key 并设置消费上限。
